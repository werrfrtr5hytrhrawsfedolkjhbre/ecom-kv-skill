## 四、使用约定

1. KV 叠字主字体为Segoe UI Symbol；文案中命中本表豆腐集的符号，按段切换 微软雅黑 混排（基线已验证可用，单色线框风格，颜色随 fill 参数）。
2. 表情类符号（⭐🔥✅❗等）即便可渲染也为单色线框稿，非彩色 emoji；需彩色请改用图片贴片。
3. 两字体并集覆盖本样本全部 95 个符号；新增符号入库前用 symbol_sweep.py 复测再归档。
4. 本表仅约束本地叠字管线；生图模型（AI 出图）内的文字不适用本表，KV 文案一律后期叠字。
