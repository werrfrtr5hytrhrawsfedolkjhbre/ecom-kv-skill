## 二、不可渲染符号 ❌（及替代建议）

| 符号 | 名称 | 替代建议 |
|---|---|---|
| ↻ | 顺时针箭头 | 用 → 加「循环」文案，或后期叠加 |
| ▶ ◀ | 实心左右三角 | 用 ▲（已验证）旋转 90° 实现 |
| ☒ | 带框叉 | 用 ✗（已验证） |
| ‰ | 千分号 | 用 % 表达，或后期叠加 |
| № | 序号符 | 写成 No. 或 # |
| ® ™ | 注册/商标符 | 用 ©（已验证）替代，或后期叠加 |
| ¶ | 段落符 | 用 • 或空行 |
| ※ | 米字号 | 用 * 或 • |
| ① ② ③ | 带圈数字（小号） | 用 ④⑤（本次通过）复检，或「阿拉伯数字 + 圆形色块底」的排版方式实现 |
| ❶ ❷ | 带圈大数字 | 同上 |
| ♦ | 菱形牌 | 用 ◆（已验证） |
| ☀ | 太阳 | 图形化元素可用 🔥/⭐（已验证）代替表达 |
| ⚠ | 警告三角 | 用文字「注意」，或后期叠加 |
| ♻ | 循环回收 | 用文字或 ↻ 的替代方案，或后期叠加 |
| ✉ | 信封 | 用文字「联系客服」，或后期叠加 |
| ☎ | 电话 | 用文字，或后期叠加 |
| ♪ | 音符 | 用文字，或后期叠加 |

> **规律**：复合字形（多部件组合：®™№‰）和细结构小图标（带圈数字、杂项小图标）是失败重灾区；单笔画几何/箭头、希腊字母、中文标点最可靠。

## 三、渲染经验（提示词建议）

1. **排布必须写死**：一律要求「整齐网格、每格一个、大间距、大小一致、垂直水平对齐、绝不重叠」；竖排单列会符号重叠
2. **复杂字形要拆解描述**：₩（W+两横）、€（C+两横）、™（T+M 上标）等复合字形需描述结构——™ 实测仍失败，这类建议直接放弃 AI 渲染
3. **一次别超 20 个**：单图符号过多明显增加粘连与错绘概率，分批渲染更稳
4. **可靠性排序**：图形化大图标（火焰/对勾/购物车）> 单笔画几何与箭头 > 希腊字母与中文标点 > 复合字形符号（货币/版权符）> 带圈数字与杂项小图标 > 长串中文文案
5. **正式投放建议**：追求零差错的符号（®™⚠☎ 等）在主图生成后用修图工具手动叠加；AI 直接渲染适合火焰/对勾/购物车/几何/箭头类
