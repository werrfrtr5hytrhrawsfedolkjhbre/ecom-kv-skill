# 千问办公 / QwenWork · 平台差异（增量）

> 只写与核心流程的差异；通用规则见 `SKILL.md` 与 `knowledge/`。
> **字段未生效兜底**：若本文件未被加载（平台读不到包内文件），按 SKILL.md 核心流程执行，生图一律走「提示词导出」，不直接调用平台生图。

## 一、生图方式

- 对话内直接调用原生能力：**以用户提供的商品图为底图做图像编辑**——保留商品主体像素级原样（含日文版权标），仅替换/扩展背景；禁止文生图重绘商品；系统**异步交付**。
- 编辑请求必须附：「画面内文字仅限简体中文、英文、数字；内嵌符号仅限本平台可渲染符号集稳定列表；禁止渲染日文及 ©®™；商品主体上的原文字保持像素级原样；文案排版对齐均匀——边框内文字居中、四边等距、段落间距均匀、按钮不叠字；抠图处理——主体边缘适度羽化减少毛刺，加阴影/倒影/环境光融入背景，透视畸变先校正」。

## 二、文字内嵌

- 仅内嵌**极短主标题（≤8 字）**；请求附「画面文字严格按原文逐字渲染：{文案}」；生图后逐字核对。
- 其余文案（副标题 / 促销 / CTA）一律不内嵌，引导用户后期排版。

## 三、符号内嵌

- 内嵌符号仅限本平台可渲染符号集稳定列表，**按当前排版字体二选一**：
  - `platforms/assets/qwenwork-symbols-segoe-ui-symbol.md`（Segoe UI Symbol，可渲染 76/95）
  - `platforms/assets/qwenwork-symbols-microsoft-yahei.md`（微软雅黑，可渲染 72/95）
- 不可渲染符号（豆腐字形）一律改为后期排版，并写入排版指引。

## 四、运营约束与限制

- 生图为内置多模态能力，无需单独开启；默认档位即可用，高档位模型效果更好。
- 个人版不能把自建技能发布到公共扩展（用 zip 分享安装）。
- 官方更新套件会覆盖个人修改。

## 五、安装

- 本地目录：`.qwen/skills` 或 `~/.qwen/skills`（或存在 `$QWEN_SKILL_ROOT` 的目录）。
- 支持上传含 SKILL.md 的 zip 包。
- 安装后在人设/配置中写死一句：**当前运行平台：千问办公**。
