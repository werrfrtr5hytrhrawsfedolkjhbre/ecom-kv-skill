# 类目场景库（电商商品主视觉 KV 场景库）

> **用途**：为电商商品主视觉 KV 图生成提供预置的人群画像（TA）与使用场景参考。
> **结构**：大类目 → 子类目 → TA 画像 / 使用场景 / KV 视觉建议。
> **使用方式**：选定子类目后，将「TA 画像 + 使用场景 + KV 视觉建议」拼入出图提示词，即可获得人群匹配、场景对位的 KV 画面。

## 一、家居日用

### 1.1 软装家具（沙发、床品、装饰画、地毯）

**TA 画像**
- 人群：25–40 岁新中产租房/首房改造人群，女性占比约 65%
- 消费力：中高，愿为「氛围感」与「出片感」买单
- 生活方式：关注家居博主、爱刷改造视频、周末逛宜家/造作
- 核心需求：低成本把家变得有格调；怕买到货不对板

**使用场景**
1. 周末午后，阳光透过纱帘洒在奶油风沙发上，用户窝在沙发里喝咖啡看书
2. 深夜卧室，暖光落地灯 + 亚麻床品，营造松弛入睡氛围
3. 朋友来家聚会，客厅地毯 + 装饰画背景成为拍照打卡位

**KV 视觉建议**
- 主色调：奶油白、燕麦色、原木色、莫兰迪低饱和色
- 风格关键词：日系奶油风 / 法式复古 / 极简侘寂，自然侧光，浅景深
- 构图：场景沉浸式（人在画面中）或空镜氛围式，商品为视觉锚点

### 1.2 收纳清洁（收纳盒、扫地机器人、清洁工具）

**TA 画像**
- 人群：22–35 岁都市白领与小户型住户，女性为主
- 消费力：中等，看重性价比与「解放双手」的效率感
- 生活方式：工作忙、通勤长，追求"10 分钟恢复整洁"
- 核心需求：省时省力、隐形收纳、告别凌乱

**使用场景**
1. 下班回家，一键启动扫地机器人，人躺沙发追剧
2. 换季整理，衣柜里收纳盒分区整齐，一目了然
3. 小户型玄关/卫生间"见缝插针"收纳，空间瞬间翻倍

**KV 视觉建议**
- 主色调：白色 + 单一清爽点缀色（薄荷绿/雾蓝）
- 风格关键词：整洁秩序感、Before/After 对比、俯拍收纳陈列
- 构图：对称分格俯拍（收纳类）；居家场景 + 机器工作路径示意（清洁电器）

### 1.3 餐厨用品（餐具、锅具、水杯、咖啡器具）

**TA 画像**
- 人群：24–38 岁"厨房治愈系"人群，独居青年与小两口
- 消费力：中高，愿为设计与仪式感付费
- 生活方式：早餐摆盘发朋友圈、手冲咖啡入门、下厨解压
- 核心需求：好看、上镜、提升一日三餐的幸福感

**使用场景**
1. 清晨，木托盘端着骨瓷杯 + 手冲壶，阳光早餐桌
2. 周末做一顿意面，铸铁锅直接端上桌当颜值担当
3. 傍晚一人食，暖灯下一碗热汤面的治愈瞬间

**KV 视觉建议**
- 主色调：暖白 + 原木 + 食物本色（焦糖色、抹茶绿等）
- 风格关键词：日式侘寂餐桌、美食摄影级打光、蒸汽感/热气
- 构图：平铺俯拍（Flat-lay）餐桌全景，或 45° 特写 + 手部互动

## 二、食品生鲜

### 2.1 休闲零食（坚果、烘焙、糖果、辣条）

**TA 画像**
- 人群：18–30 岁 Z 世代学生与职场新人，男女均衡
- 消费力：中低，高频复购，冲动型下单
- 生活方式：追剧搭子、下午茶补给、宿舍/工位囤货
- 核心需求：解馋、解压、大分量划算、包装有趣可晒

**使用场景**
1. 深夜追剧，抱着一桶坚果瘫在沙发上
2. 办公室下午 3 点，抽屉里的零食拯救低血糖
3. 宿舍夜谈会，辣味零食是社交货币

**KV 视觉建议**
- 主色调：高饱和撞色（橙红/明黄），零食本色放大呈现
- 风格关键词：食欲暴击、动态"飞溅/爆开"瞬间、大特写
- 构图：微距食物特写 + 饱满堆叠感（"量多管饱"视觉暗示）

### 2.2 生鲜食材（牛排、海鲜、水果、预制菜）

**TA 画像**
- 人群：28–45 岁家庭餐桌决策者，已婚有孩，女性为主
- 消费力：中高，为"新鲜、安全、省事"付溢价
- 生活方式：线上买菜常态化、注重营养搭配
- 核心需求：产地直采、锁鲜、开袋即烹

**使用场景**
1. 晚餐时刻，妈妈端出 10 分钟搞定的预制硬菜，全家称赞
2. 周末家庭牛排晚餐，铸铁锅滋滋作响的仪式感
3. 开箱即见冰袋锁鲜 + 饱满果径，安全感拉满

**KV 视觉建议**
- 主色调：食材本色 + 冷链蓝/冰晶元素（传达新鲜）
- 风格关键词：水珠飞溅、冰鲜质感、热气腾腾的成品菜
- 构图：食材原料与成品菜同框"蜕变对比"，突出锁鲜链路图标

### 2.3 健康轻食（代餐、低卡、粗粮、无糖饮料）

**TA 画像**
- 人群：20–35 岁健身与控体人群，一线/新一线城市，女性 70%
- 消费力：中高，为成分与功效买单，会看配料表
- 生活方式：健身房打卡、体重管理、办公室轻食午餐
- 核心需求：低卡饱腹、0 糖 0 负担、好吃不断粮

**使用场景**
1. 健身房练完，摇一杯蛋白代餐当晚餐
2. 办公室午餐，一份颜值在线的低卡沙拉碗
3. 夏日午后，冰镇无糖气泡水替代奶茶

**KV 视觉建议**
- 主色调：清透绿、白、浅蓝，"干净成分表"式留白
- 风格关键词：轻盈通透、食材原料可视化（燕麦/水果切片悬浮）
- 构图：产品 + 原料环绕式；大字卖点（0 糖 / 低卡 / 高蛋白）叠加

## 三、3C 数码

### 3.1 手机与配件（手机壳、充电器、耳机、支架）

**TA 画像**
- 人群：18–35 岁学生与年轻职场人，男女均衡
- 消费力：中，配件高频换新，追性价比与颜值
- 生活方式：重度手机用户、通勤听歌、桌搭文化
- 核心需求：快充、颜值、轻薄便携、拍照好看

**使用场景**
1. 地铁通勤，降噪耳机隔绝嘈杂世界
2. 桌搭工位，透明手机壳 + 磁吸支架组成的精致角落
3. 出差旅行，一个多口充电器搞定所有设备

**KV 视觉建议**
- 主色调：深空灰 + 电光蓝/紫渐变，科技感高对比
- 风格关键词：悬浮渲染（C4D 风）、光效穿透、磁吸吸附动态
- 构图：产品居中悬浮 + 参数大字；或场景代入（通勤/桌搭）

### 3.2 电脑办公（笔记本、键盘、显示器、扩展坞）

**TA 画像**
- 人群：24–40 岁程序员/设计师/自媒体人，男性偏多
- 消费力：高，为生产力与效率付费，决策周期长
- 生活方式：居家办公混合模式、键盘圈/桌面圈玩家
- 核心需求：性能、护眼、多屏协同、手感

**使用场景**
1. 夜晚居家办公，双屏 + 氛围灯带的高效工位
2. 咖啡馆远程办公，轻薄本 + 便携支架
3. 深夜赶方案，机械键盘敲击声带来的专注心流

**KV 视觉建议**
- 主色调：深色系（石墨黑/午夜蓝）+ RGB 点缀光
- 风格关键词：赛博工位、屏发光照亮桌面、极客质感特写
- 构图：第一/第三人称工位视角，屏幕内容可视化（代码/设计稿）

### 3.3 智能穿戴（手表、手环、智能眼镜）

**TA 画像**
- 人群：20–40 岁运动爱好者与健康管理人群
- 消费力：中高，愿为健康数据与科技体验付费
- 生活方式：晨跑、骑行、睡眠监测、社交晒运动轨迹
- 核心需求：精准监测、长续航、运动场景耐用

**使用场景**
1. 清晨 5 点晨跑，手表抬腕查看配速与心率
2. 健身房撸铁，手环记录每组训练数据
3. 睡前查看睡眠报告，调整作息

**KV 视觉建议**
- 主色调：活力橙/荧光绿 + 深色运动背景
- 风格关键词：运动张力（肌肉线条/汗水）、数据 UI 悬浮界面
- 构图：抬腕特写 + 动态模糊背景，传达"运动中监测"

## 四、美妆个护

**TA 画像**
- 人群：18–35 岁女性为主，成分党与早 C 晚 A 一族
- 消费力：中高，按功效买单，复购忠诚
- 生活方式：护肤流程仪式化、跟风测评博主
- 核心需求：功效实证（美白/抗老/修护）、温和不刺激

**使用场景**
1. 睡前梳妆台，灯光下涂抹精华的护肤仪式
2. 早晨出门前，防晒上脸的最后一步
3. 换季敏感期，一片修护面膜的急救时刻

**KV 视觉建议**
- 主色调：功效色系——美白用珍珠白/透蓝，抗老用金棕，修护用治愈绿
- 风格关键词：水润质感、精华液滴落/拉丝特写、成分可视化（烟酰胺分子/植物元素）
- 构图：产品 + 膜布/精华质地的微距组合，皮肤透亮感

### 4.2 彩妆（口红、粉底、眼影、腮红）

- 核心需求：显色持妆、色号氛围感、平价不踩雷

**使用场景**
1. 约会前，对镜涂上"斩男色"口红的紧张与期待
2. 闺蜜宿舍夜话，互相试色的新色号开箱
3. 通勤早八，5 分钟快手妆的底气

**KV 视觉建议**
- 主色调：当季流行色大色块（枫叶红/蜜桃粉/烟紫色）
- 风格关键词：高级感色板陈列、唇模/眼妆特写、膏体质地放大
- 构图：多色号矩阵排列 + 单色大特写；模特局部妆面 + 产品

### 4.3 个护电器（吹风机、电动牙刷、美容仪）

- 构图：宝宝 + 产品安全距离同框，洁净浅色背景 + 权威背书图标

- 构图：儿童视角低机位，产品 + 孩子互动瞬间
