# 电商营销主视觉设计硬规则

> **用途**：skill 所有设计决策的底层依据——提案中每条「设计理由」必须对应到规则编号；成品交付前必须逐条通过（对照《自检清单》）。
> **地位**：10 条规则全部为硬性要求，任何平台、任何类目、任何方案都不允许例外或打折。与用户要求冲突时，先解释规则再执行。
> **配套**：规则 P2/P3 的落地方法见《卖点提炼规则》，文案工具见《文案模板库》，画面场景参考《类目场景库》，尺寸与安全区数值见《电商平台规范表》。

---

## 一、规则总表

| 编号 | 原则 | 一句话要求 |
|------|------|-----------|
| P1 | 3 秒法则 | 画面信息按「商品主体 > 主卖点 > 促销/价格 > CTA」排序，主卖点必须一眼可见 |
| P2 | 单一主卖点 | 一张图只讲一个核心价值，辅助卖点 ≤ 2 个且视觉上弱于主卖点 |
| P3 | 利益导向 | 所有文案落到消费者利益（FAB 法则），禁止纯参数堆砌 |
| P4 | 视觉层级 | 主体与背景对比明确；文字可读性优先 |
| P5 | 信息密度 | 文字占画面面积 ≤ 30%，留白充足 |
| P6 | 场景代入 | 优先使用 TA 使用场景图，纯白底仅用于平台强制要求的类目 |
| P7 | 合规优先 | 违禁词零容忍；不用未授权 IP/明星/logo；促销表述真实 |
| P8 | AIDA 完整 | 注意力→兴趣→欲望→行动，四要素缺一不可 |
| P9 | 平台适配 | 关键信息在安全区内；尺寸像素精确符合电商平台规范 |
| P10 | 真实商品图 | 商品主体必须来自用户提供的商品图（抠图使用），禁止 AI 重绘商品形象 |

## 二、逐条细则

### P1 3 秒法则

**含义**：消费者在信息流中约 3 秒决定是否点击。3 秒内必须看懂「是什么商品 + 为什么值得买 + 下一步做什么」。

**硬性要求**：
- 画面视觉权重从高到低：商品主体 → 主卖点文案 → 促销/价格 → CTA
- 主卖点在缩略图尺度（约 150×150px）下依然可辨认
- 第一眼焦点必须是商品或主卖点，禁止背景装饰喧宾夺主
- 商品主体优先，但主体占比过大挤压文案区时**可适当缩小主体**（缩略图下仍可辨认即可），保证文案区有呼吸空间

**示例**：
- ❌ 商品缩在角落，背景大片风景
- ❌ 主卖点用浅色小字压在复杂背景上
- ✅ 商品主体占画面 50% 以上 + 主卖点大字高对比

### P2 单一主卖点

**硬性要求**：
- 一张图只讲一个核心价值，即《卖点提炼规则》三维打分确定的主打卖点
- 辅助卖点 ≤ 2 个，且字号、色彩权重明显弱于主卖点
- 主标题、画面文案、KV 主体三者口径一致，都围绕同一个主卖点

**示例**：
- ❌ 一张图同时强调「大吸力 + 长续航 + 超轻量」三个同等权重的卖点
- ✅ 主卖点「150AW 吸力」占 C 位，续航与轻量以小字角标呈现

### P3 利益导向

**硬性要求**：
- 所有文案必须落到消费者利益 B（FAB 法则，见《卖点提炼规则》），禁止 F 参数裸奔
- 画面中出现的每个数字都要让消费者看懂「这对我意味着什么」

**示例**：
- ❌ 「316 不锈钢」「150AW 吸力」单独出现无解释
- ✅ 「316 不锈钢内胆，泡茶泡咖啡不留味」「150AW 吸力，床单一遍吸出看不见的脏」

### P4 视觉层级

**硬性要求**：
- 主体与背景对比明确：明度差、色相差、虚实差至少占其一
- 文字可读性优先：禁花体字、禁低对比配色（如浅黄字白底）
- 每张图 ≤ 2 个字体家族、≤ 3 级字号层级
- 排版严格对齐均匀：边框/色块内的文字水平垂直居中，且到四边距离相等
- 段落间距均匀、行距不挤不散；按钮/徽章内文字完整显示，不叠字、不过挤

**示例**：
- ❌ 金色细体字放在米色背景上
- ✅ 白色粗体主标题 + 深色压边背景，次级信息用小一号字

### P5 信息密度

**硬性要求**：
- 文字占画面面积 ≤ 30%，留白充足
- 核心文案区块 ≤ 3 块（主标题区 / 促销区 / CTA 区）；另可设 1 个「信息条目区」（规格/参数/材质/服务等商品信息条目 2~5 行，均匀排布，不计入 3 块）
- 未指定投放平台时：按非信息流标准执行，并**尽量展示用户提供的商品信息**（信息条目区取满 5 行）
- 信息流场景（抖音商城、小红书）按更严标准执行：文字面积 ≤ 20%，信息条目区 ≤ 3 行

### P6 场景代入

**硬性要求**：
- 优先使用 TA 使用场景图（对照《类目场景库》对应子类目），增强代入感
- 纯白底仅用于平台强制要求的类目（见《电商平台规范表》，如京东主图）
- 场景必须与 TA 画像逻辑一致，能自圆其说
- 氛围质感：必须执行《类目场景库》对应子类目的「KV 视觉建议」（风格关键词/主色调/构图），按商品类型营造高级感与氛围感（质感光效、景深、材质高光、色调统一），禁止平淡土气的平涂式构图

**示例**：
- ❌ 目标人群是宝妈，画面却是商务办公室场景
- ✅ 保温杯 + 清晨通勤/办公桌场景，直击目标人群使用时刻

### P7 合规优先

**硬性要求**：
- 广告法违禁词零容忍：对照《广告法违禁词清单》逐词检查，命中即改写并标注改写原因
- 不用未授权 IP / 明星 / 品牌 logo
- 促销表述必须真实可兑现（价格、赠品、时限与实际活动一致）
- 功效类卖点必须有实证依据（检测报告 / 实测数据）

### P8 AIDA 完整

**硬性要求**：四要素缺一不可，缺少任一要素判不通过。

| 要素 | 对应画面元素 | 缺失表现 |
|------|------------|---------|
| A 注意力 | 大主体 / 强对比 | 画面平淡，信息流中无停留 |
| I 兴趣 | 主卖点 | 看完不知道好在哪 |
| D 欲望 | 促销 / 场景共鸣 | 想买但没理由现在买 |
| A 行动 | 明确 CTA | 没有引导，看完划走 |

### P9 平台适配

**硬性要求**：
- 关键信息（主卖点 / 价格 / CTA）必须落在安全区内，避开四角角标与平台按钮位置
- 尺寸像素、比例、文件大小精确符合《电商平台规范表》
- 同一设计语言适配不同画幅（1:1 → 3:4）时重新构图，禁止简单拉伸裁剪

### P10 真实商品图

**含义**：画面中的商品形象必须与真实商品完全一致。AI 重绘的商品与实际商品有差异，消费者收货后产生落差 → 差评、退款、投诉；动漫/游戏周边类还会破坏版权授权标识、角色形象变形。

**硬性要求**：
- 商品主体一律从用户提供的商品图中抠取（抠图、修整光影、去除原背景后合成到新场景）
- 禁止 AI 重新生成 / 重绘商品形象（包括所谓「美化版」「更精致版」）
- 用户商品图不清晰、角度不合适 → 请用户重新提供，禁止 AI 补全细节
- 授权标、品牌 logo、防伪标必须原样保留，禁止重绘、擦除或遮挡
- 版权标/授权标文字（含日文、©®™）禁止交给生图模型渲染（实测各平台生图对 ©®™ 均不稳定）：要么随商品原图像素级保留，要么由用户用排版工具后期添加；生图画面文字仅限中文、英文、数字，符号仅限各平台《可渲染符号集》稳定列表
- 参考图仅用于风格/构图参考，不得替代真实商品图
- 抠图与融合：商品主体边缘适度虚化（羽化）减少毛刺；透视明显畸变时校正角度或请用户提供平视角图；合成后加阴影/倒影/环境光使主体融入背景，避免「贴纸感」割裂

**示例**：
- ❌ 用户发了死神吧唧照片，成品图里吧唧被 AI 重绘成「相似款」，授权标丢失
- ✅ 抠出原商品主体，仅替换背景与文案区，吧唧图案和授权标原样保留

## 附：规则冲突时的优先级

当规则互相冲突（如平台强制白底 vs 场景代入），按以下顺序取舍：

1. **P7 合规优先、P10 真实商品图**——法律与真实性底线，任何情况下不妥协
2. **P9 平台适配**——平台审核不通过 = 图无法使用
3. **P1 3 秒法则** > **P2 单一主卖点** > **P8 AIDA** > **P4 / P5 / P6** > **P3**

> 例 1：京东强制白底（P9）与场景代入（P6）冲突 → 服从 P9。
> 例 2：大促想塞更多信息（P5）与 3 秒法则（P1）冲突 → 服从 P1，砍信息到 3 块以内。
