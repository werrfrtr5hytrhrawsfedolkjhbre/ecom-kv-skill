# 营销主视觉自检清单

> **用途**：提案输出前与成品交付前的强制检查表。任何一项「不通过」→ 不得交付，必须附修改建议。所有平台共用。
> **配套**：检查依据为《设计硬规则》10 条；违禁词对照《广告法违禁词清单》；卖点口径对照《卖点提炼规则》；文案句式对照《文案模板库》；尺寸数值对照《电商平台规范表》。
> **输出**：每次自检输出《自检报告》（格式见第三节），随提案或成品一并交付。

---

## 一、检查总表

### A 卖点与文案层

| 编号 | 检查项 | 判定标准 | 规则 |
|------|--------|---------|------|
| A1 | 主卖点唯一性 | 全图只讲一个主卖点，且为利益句（B），非参数裸奔 | P2 / P3 |
| A2 | 辅助卖点数量 | ≤ 2 个，字号/色彩权重明显弱于主卖点 | P2 |
| A3 | 主标题长度 | ≤ 15 字，5 秒内能读懂核心利益 | P1 |
| A4 | 副标题支撑 | 回答了「凭什么」（成分/销量/认证/对比） | P3 |
| A5 | 口径一致 | 画面文案与提案文案、主卖点主张口径一致 | P2 |
| A6 | 促销真实性 | 促销机制真实可兑现，有明确数字与时限 | P7 |

### B 画面层

| 编号 | 检查项 | 判定标准 | 规则 |
|------|--------|---------|------|
| B1 | 3 秒可读 | 商品主体 + 主卖点在缩略图尺度（约 150px）可辨认；主体过大挤压文案区时已适当缩小 | P1 |
| B2 | 视觉层级 | 主体与背景对比明确（明度/色相/虚实至少其一），文字可读 | P4 |
| B3 | 信息密度 | 文字面积 ≤ 30%（信息流 ≤ 20%）；核心文案区 ≤ 3 块 + 信息条目区 ≤ 5 行（信息流 ≤ 3 行）；未指定平台时尽量展示商品信息 | P5 |
| B4 | 字体规范 | ≤ 2 个字体家族、≤ 3 级字号层级，无花体字 | P4 |
| B5 | 场景代入 | 场景与 TA 画像一致；白底仅在平台强制时使用 | P6 |
| B6 | CTA 存在 | 有明确行动号召（点击 / 领券 / 加购…） | P8 |
| B7 | AIDA 完整 | 注意力→兴趣→欲望→行动四要素齐全 | P8 |
| B8 | 文字准确性 | 画面文字与提案文案逐字一致（含符号），无错字/漏字/乱码；内嵌符号均在本平台《可渲染符号集》稳定列表内 | P4 |
| B9 | 排版对齐均匀 | 边框/色块内文字居中且到四边距离相等；段落间距均匀不挤；按钮/徽章不叠字、不过挤 | P4 |
| B10 | 抠图与融合 | 商品边缘虚化无毛刺；透视无明显畸变；阴影/倒影/环境光使主体融入背景，无贴纸感 | P10 |

### C 合规层

| 编号 | 检查项 | 判定标准 | 规则 |
|------|--------|---------|------|
| C1 | 违禁词 | 《广告法违禁词清单》0 命中（含价格类极限词） | P7 |
| C2 | 授权元素 | 无未授权 IP / 明星 / 品牌 logo | P7 |
| C3 | 功效实证 | 功效类卖点有实证依据（检测报告 / 实测数据） | P7 |
| C4 | 商品真实性 | 商品主体与用户提供的商品图一致（抠图/背景替换，非 AI 重绘）；授权标/logo 原样保留、版权标文字无错字乱码（禁止生图渲染版权标文字） | P10 |

### D 交付层

| 编号 | 检查项 | 判定标准 | 规则 |
|------|--------|---------|------|
| D1 | 尺寸比例 | 像素与比例精确符合《电商平台规范表》 | P9 |
| D2 | 文件大小 | 在平台限额内（3M / 5M） | P9 |
| D3 | 安全区 | 主卖点/价格/CTA 避开四角与边缘 10% 区域 | P9 |
| D4 | 平台特殊项 | 白底 / 无大面积文字 / 主体占比 70% / 无二维码 / 无极限词逐项通过 | P9 |

---

## 二、检查时机

| 时机 | 检查范围 |
|------|---------|
| 提案输出前 | A 层全部（卖点与文案成立才允许出提案） |
| 成品交付前 | A–D 层全部，任何一项不通过不得交付 |
| 迭代修改后 | 受影响项复查 + B/D 层全查 |

---

## 三、自检报告模板

```
《自检报告》
检查对象：（方案 N 提案 / 成品图 / 修改稿）
检查时间：（日期）
结论：通过（24/24） / 不通过（X 项）

不通过项及修改建议：
1. [B3 信息密度] 文字面积约 45%，超出 30% 上限
   建议：副标题移出画面，只保留主标题 + 促销 + CTA 三块
2. [C1 违禁词] 主标题含「全网最低」
   建议：改写为「到手价 79 元，今日直降 20 元」

通过项（简列编号）：A1 A2 A3 …
```

## 附：快速自测 15 问（人工目测版）

1. 眯起眼睛 3 秒，能说出这是什么商品、好在哪吗？（B1）
2. 这张图讲的是不是只有一个卖点？（A1）
3. 主卖点里的数字，我（消费者）看得懂对我意味着什么吗？（A3）
4. 文字和背景分得清吗？有没有花体字？（B2）
5. 文字面积有没有超过画面的 1/3？（B3）
6. 画面场景是不是目标人群的真实使用场景？（B5）
7. 有没有明确告诉消费者下一步做什么？（B6）
8. 有没有「最/第一/国家级」等词？（C1）
9. 尺寸、文件大小、白底要求符合平台规范吗？（D1/D2/D4）
10. 关键信息会不会被平台角标挡住？（D3）
11. 画面里的商品和用户发的图一模一样吗？有没有被 AI 重绘？授权标还在吗？（C4）
12. 画面里的中文逐字读一遍，有没有错字/漏字/乱码？（B8）
13. 文字块里的字居中吗？到四边距离相等吗？按钮有没有叠字？（B9）
14. 商品边缘有毛刺吗？主体和背景融合吗，还是像贴纸？（B10）
15. 画面有高级感/氛围感吗，还是土气平涂？（B5/B6）
