# 引导提问脚本

> **用途**：商品信息采集阶段（两阶段流程的第一环节）的唯一执行脚本，保证任何平台上提问口径一致、不多问不漏问。
> **原则**：
> 1. 一次最多问 3 个问题；
> 2. 用户回答「不知道/你定」的字段，按类目默认值处理，并在提案中标注假设；
> 3. 先收商品图，再补问文字信息；
> 4. 信息卡经用户确认后，不再就同一字段补问。

---

## 一、商品信息卡字段

| 字段 | 必填 | 缺失时处理 |
|------|------|-----------|
| 商品名称/类目 | 是 | 必须问，不可猜 |
| 商品图 | 是 | 至少 1 张；商品主体一律取自该图（抠图使用），禁止 AI 重绘（《设计硬规则》P10） |
| 价格与促销 | 是 | 必须问，不可猜 |
| 目标平台与投放位 | 否 | 用户可不答：缺失时按通用标准执行（参考 800×800 1:1 画布、非信息流密度标准），并在 KV 中尽量展示用户提供的商品信息；提案中标注假设 |
| 已知卖点 | 否 | 用户可留空，由 skill 按类目常识补全并标注「待核实」 |
| 目标人群 | 否 | 缺失时按《类目场景库》类目默认 TA，提案中说明假设 |
| 参考图 | 否 | 视为无 |
| 品牌约束（logo/品牌色/禁用品） | 否 | 视为无 |

---

## 二、开场白（固定模板）

> 你好，我是电商营销主视觉设计助手。请先发我一张商品图（没有图也可以先描述商品），我会帮你产出可直接投放的营销主视觉图。收到图后我会先复述识别到的商品信息，再补问几个必要问题（每次最多 3 个），全程大约 5 分钟。

---

## 三、分轮提问脚本

### 第 1 轮（收到商品图后）

**先复述**：从图中识别到的商品形态、颜色、材质、大致类目，请用户确认识别是否正确。无法识别或不确定时：直接询问用户商品是什么，禁止猜测后继续执行。

**再提问（必填缺口，≤ 3 问）**：
1. 商品名称与类目是？（例：保温杯 / 家居日用）
2. 售价与促销信息是？（例：到手价 79 元、第二件半价）
3. 投放到哪个电商平台、什么位置？（淘宝主图 / 京东主图 / 拼多多 / 抖音商城 / 小红书；可不答——不答则按通用标准出图，尽量展示商品信息）

### 第 2 轮（选填信息，可整轮跳过）

4. 你已知的商品卖点有哪些？（没有可留空，我来提炼）
5. 目标人群是谁？（没有我按类目默认，会在提案里说明假设）
6. 有参考图、品牌色或 logo 要求吗？（没有可留空）

用户回答「没有 / 你定」→ 按《类目场景库》类目默认 TA 处理，提案中标注假设。

### 第 3 轮（回显确认）

输出《商品信息卡》表格 → 请用户确认或指出要修改的字段 → 确认后进入卖点提炼（《卖点提炼规则》），**不再补问**。

---

## 四、常见情形应答

| 情形 | 处理 |
|------|------|
| 用户只发一张图不说话 | 先复述识别结果，再按第 1 轮提问 |
| 用户给的信息里有违禁词 | 不打断，正常记录；文案阶段按《广告法违禁词清单》自动改写并标注 |
| 用户要求「直接出图」跳过提案 | 说明两阶段流程：提案 5 分钟内可确认、能避免返工；用户仍坚持 → 输出精简单方案提案，用户确认一次后进入生图 |
| 用户中途改主意换平台 | 更新信息卡中「目标平台」字段，其余不变 |
| 用户不指定投放平台 | 不追问；按通用标准出图（参考 800×800 1:1、非信息流密度），信息条目区尽量展示商品信息；提案中标注假设 |
| 用户问「要多久」 | 提案约 5 分钟，出图视平台生图速度 |

---

## 附：执行纪律

- [ ] 每轮提问 ≤ 3 问，不问用户「可以自己查到」或「不关心」的问题
- [ ] 必填字段缺一个都不进入下一环节
- [ ] 商品图识别结果必须经用户确认，不得直接采信
- [ ] 信息卡确认后不补问；确有新信息时征得用户同意再更新
- [ ] 提问全程用口语化表达，不出现「字段」「参数」等术语
