# 电商商品营销文案模板库

> **用途**：为电商商品主图、详情页、大促会场、投放素材提供主标题 / 副标题 / 促销 / CTA 四层句式模板。
> **结构**：通用句式框架（带占位符）→ 十大品类专属模板 → 营销场景组合矩阵。
> **占位符说明**：`{人群}` `{卖点}` `{数字}` `{场景}` `{痛点}` `{机制}` `{时限}` 填入商品实际信息即可产出文案。
> **搭配使用**：与《类目场景库》同品类对照使用——场景库定画面，本库定文字。

---

## 一、通用句式框架（全品类适用）

### 1.1 主标题句式（8–15 字，一击命中）

| # | 句式 | 适用倾向 |
|---|------|---------|
| T1 | {数字}{核心利益}，{数字}{佐证} | 数据型卖点 |
| T2 | {痛点}？这{品类}一次解决 | 痛点直击 |
| T3 | {人群}的{美好状态}，从它开始 | 人群共鸣 |
| T4 | {卖点}天花板，闭眼入不踩雷 | 销量型话术 |
| T5 | 一{量词}搞定{场景动词短语} | 效率承诺 |
| T6 | {圈层黑话/流行语}，懂的都懂 | Z世代/圈层 |
| T7 | 把{美好事物}带回家 | 情绪价值 |
| T8 | {权威背书}×{核心卖点}，{品类}新标准 | 高客单/科技 |

### 1.2 副标题句式（补充证据与细节）

| # | 句式 | 功能 |
|---|------|------|
| S1 | {成分/材质/工艺}加持，{效果}看得见 | 讲"凭什么" |
| S2 | 已售{数字}+，回购率{数字}% | 讲"多少人买" |
| S3 | {痛点场景}，它替你{解决方案} | 讲"何时用" |
| S4 | {对比参照物}的体验，{价格锚点}的价格 | 讲"值不值" |
| S5 | {认证/联名/专利}，妈妈/达人都在用 | 讲"谁背书" |

### 1.3 促销句式（制造紧迫与获得感）

| # | 句式 | 心理机制 |
|---|------|---------|
| P1 | 限时直降{金额}，到手仅{价格} | 价格锚点 |
| P2 | 前{数字}名{加赠/半价}，抢完即止 | 稀缺抢占 |
| P3 | 买{正装}送{同款/小样}，等于{折扣力度} | 超值感换算 |
| P4 | {大促节点}专属：{机制}，一年仅此一次 | 节点正当性 |
| P5 | 跨店满{金额}减{金额}，叠券更省 | 凑单引导 |
| P6 | 价保{时长}，买贵退差 | 打消观望 |
| P7 | 拍{数字}件享{递增优惠}，囤一年的量 | 囤货逻辑 |

### 1.4 CTA 句式（临门一脚）

| # | 句式 | 触发动作 |
|---|------|---------|
| C1 | 点击领取{利益}，立即抢购 | 直球型 |
| C2 | 手慢无！{时限}后恢复原价 | 倒计时型 |
| C3 | 加入购物车，{美好结果}今天到家 | 结果预演型 |
| C4 | 先领券再下单，立省{金额} | 省钱路径型 |
| C5 | 好物不等人，点击直达会场 | 大促导流型 |
| C6 | 现在下单，{附加权益}一起带走 | 加赠提醒型 |

### 1.5 信息条目句式（KV 信息条目区，2~5 行）

| # | 句式 | 示例 |
|---|------|------|
| I1 | {参数}：{数字}{单位} | 容量：500ml |
| I2 | {材质/工艺}，{好处} | 316 不锈钢内胆，不留味 |
| I3 | {服务承诺} | 7 天无理由退换 |
| I4 | {认证/背书} | 国家质检认证 |

> 使用规则：每条 ≤ 12 字；条目区整体均匀排布、行距一致（P4 对齐均匀）；未指定投放平台时条目区可放满 5 行（P5）。

## 三、营销场景组合矩阵

> 同一商品在不同营销节点，用「场景策略 × 句式组合」切换文案气质。

### 3.1 新品上市

**策略**：造悬念、立认知、首发权益
- 主标题用 T8（背书×卖点）/ T3（人群共鸣）
- 副标题用 S1（讲凭什么）+ S5（讲谁背书）
- 促销：`首发价直降{金额}，{时限}后恢复原价`
- CTA：`新品首发，抢先体验点击立抢`（C1）

### 3.2 日常种草（信息流/详情页首屏）

**策略**：场景代入、痛点共鸣、弱促销
- 主标题用 T2（痛点直击）/ T5（效率承诺）
- 副标题用 S3（何时用）+ S4（值不值）
- 促销：`日常好价，买{正装}送{小样}`
- CTA：`点击看看，{美好结果}在等你`（C3）

### 3.3 大促节点（618 / 双11 / 年货节）

**策略**：机制复杂化、囤货正当性、价格锚点全开
- 主标题用 T4（天花板闭眼入）/ T1（数字利益）
- 副标题用 S2（销量佐证）+ S4（价格对比）
- 促销：`跨店满{金额}-{金额}，叠{品类}券再省，前{数字}名加赠{赠品}`（P2+P4+P5 三连）
- CTA：`一年一次，点击直达会场抢{利益}`（C5）

### 3.4 清仓尾货 / 断码

**策略**：坦诚降价、制造稀缺、打消疑虑
- 主标题：`{品类}清仓，{折扣力度}折封顶`
- 副标题：`正品保证，只是断码/临期{时长}，品质不变`
- 促销：`一口价{价格}，卖完永久下架`
- CTA：`码数不多，手慢真的无`（C2）

### 3.5 直播间专用

**策略**：口语化、短句、高频指令
- 主标题（口播）：`家人们，{卖点}直接冲`
- 副标题（贴片）：`库存只剩{数字}单，{折扣}价最后一波`
- 促销：`直播间专属：拍一发二，下播恢复原价`
- CTA：`{数字}号链接，左下角直接拍！`（C1 变体）

## 四、完整组合示例

以「食品-健康轻食-无糖气泡水」为例，按场景各出一套：

**新品上市**
- 主标题：0糖0卡的快乐水，夏天放心吨吨吨
- 副标题：赤藓糖醇代糖配方，控糖人群的冰爽解药

- CTA：新品首发，点击抢首批体验装

**日常种草**
- 主标题：戒不掉汽水？这瓶喝了没负担
- 副标题：下午 3 点的困意，交给它冰镇解决
- CTA：点击下单，冰箱塞满快乐

**大促节点**
- 主标题：全网卖爆的无糖气泡水，双11囤货天花板
- 副标题：已售 100 万+ 箱，回购率 60%
- 促销：跨店满 300-50，叠品类券再省 20，前 1000 名加赠 6 瓶
- CTA：一年一次，点击直达会场囤一夏天的量

## 附：使用检查清单

产出文案后逐项自检：

- [ ] 主标题 ≤ 15 字，5 秒内能读懂核心利益
- [ ] 副标题回答了"凭什么"（成分/销量/认证/对比）
- [ ] 促销句有明确数字与机制，无"低价"等模糊词
- [ ] CTA 有具体动作 + 利益点，且全渠道一致
- [ ] 广告法合规：无"最""第一""国家级"等极限词，功效类目有实证依据
- [ ] 与 KV 画面主色调、场景氛围匹配（对照《类目场景库》）
