# 电商商品卖点提炼规则

> **用途**：把商品参数表 / 详情页信息，提炼为可进入 KV 画面与营销文案的**优质卖点**。
> **流程**：卖点池穷举 → **三维打分法**筛出主打卖点 → **FAB 改写模板**翻译成用户语言 → 正反例校准。
> **配套**：本库是《类目场景库》《文案模板库》的上游——先提炼卖点，再套文案句式，最后进 KV 画面。

---

## 一、卖点提炼总流程

```
第 1 步  罗列卖点池      —— 从参数表/详情页/评论/竞品中穷举 10-20 条原始卖点
第 2 步  三维打分筛选    —— 每条卖点按三维打分，砍到 1-3 条主打卖点
第 3 步  FAB 改写       —— 把技术语言翻译成用户利益
第 4 步  分层使用        —— 主打卖点进主标题/KV 主画面，次级卖点进副标题/详情页
```

**卖点池的四个来源**（罗列阶段不限量，宁滥勿缺）：

| 来源 | 提取什么 | 举例（无线吸尘器） |
|------|---------|------------------|
| 参数表 | 技术指标 | 150AW 吸力、60 分钟续航、1.5kg 机身 |
| 用户评论 | 真实使用反馈 | "吸完床单看不到螨虫尸体了""单手能举" |
| 竞品对比 | 人无我有 / 人有我优 | 竞品续航 45 分钟 |
| 使用场景 | 什么时刻被需要 | 租房搬家、有宠物家庭、车内清洁 |

## 二、三维打分法

### 2.1 三个维度定义

对卖点池中每一条卖点，按以下三维各打 **1–5 分**，总分 15 分。

#### 维度一：需求强度（用户有多想要？）

| 分值 | 判断标准 |
|-----|---------|
| 5 | 不解决就难受的痛点（床垫螨虫、宝宝红屁屁、通勤耳机断连） |
| 4 | 明确的功能期待，购买决策的主要动机 |
| 3 | 加分项，没有也会买，有了更开心 |
| 2 | 锦上添花，感知微弱 |
| 1 | 厂商自嗨型参数，用户无感（"采用 XX 架构"） |

#### 维度二：差异度（竞品能不能也这么说？）

| 分值 | 判断标准 |
|-----|---------|
| 5 | 人无我有：独家技术/成分/设计，竞品短期内无法跟进 |
| 4 | 人有我优：同维度数字/体验显著领先（1.5 倍以上） |
| 3 | 处于第一梯队，但与头部竞品差距不大 |
| 2 | 行业平均水平 |
| 1 | 全员标配（食品"真材实料"、手机"高清屏幕"） |

#### 维度三：可感知度（用户信不信、看得见吗？）

| 分值 | 判断标准 |
|-----|---------|
| 5 | 肉眼可验证 / 有权威实证（吸尘器倒出灰尘、临床数据、检测报告） |
| 4 | 可通过对比图/演示视频直观呈现 |
| 3 | 需要解释，但解释后能懂 |
| 2 | 长期使用才能隐约感知（"延长机器寿命"） |
| 1 | 无法验证的主观描述（"高端""匠心"） |

### 2.2 打分与决策规则

**总分管控：**

| 总分 | 定位 | 用法 |
|-----|------|------|
| 12–15 | **主打卖点** | 进主标题 + KV 画面主体，最多 1–2 条 |
| 9–11 | 次级卖点 | 进副标题、详情页模块、卖点角标 |
| ≤8 | 淘汰或备选 | 不上主视觉；详情页底部或干脆放弃 |

**一票否决项**（任一维度得 1 分，无论总分多少直接淘汰或重写）：
- 差异度 = 1：说了等于没说，浪费 KV 黄金位
- 可感知度 = 1：无法验证 = 用户不信 = 无效沟通

**单维度封顶项**（该维度 = 5 时可破格提升优先级）：
- 需求强度 = 5 的痛点型卖点，即使差异度一般也值得进入前 3（痛点共鸣自带流量）

### 2.3 打分示例（无线吸尘器）

| 卖点 | 需求强度 | 差异度 | 可感知度 | 总分 | 结论 |
|------|:---:|:---:|:---:|:---:|------|
| 150AW 大吸力 | 5 | 4 | 5 | **14** | 主打：吸力即正义 |
| 60 分钟长续航 | 4 | 4 | 4 | 12 | 主打/次级 |
| 1.5kg 轻量机身 | 4 | 3 | 5 | 12 | 次级（女性用户提为主打） |
| LED 照明吸头 | 3 | 3 | 5 | 11 | 次级：床底灰尘可见 |
| 第 X 代电机架构 | 1 | 3 | 1 | 5 | **淘汰**：厂商语言，用户无感 |
| "匠心工艺" | 2 | 1 | 1 | 4 | **淘汰**：一票否决×2 |

> 注意第 3 行：同一卖点对不同 TA 权重不同——女性/长辈用户群体中"轻"可升为主打。**打分要带着 TA 画像打**（对照《类目场景库》对应子类目）。

## 三、FAB 改写模板

### 3.1 什么是 FAB

| 层 | 含义 | 语言类型 | 示例（吸尘器） |
|----|------|---------|--------------|
| **F** Feature 属性 | 产品是什么/有什么 | 工程师语言 | 150AW 吸力 |
| **A** Advantage 优势 | 比别人好在哪 | 销售语言 | 吸力是普通无线款的 1.5 倍 |
| **B** Benefit 利益 | 用户得到什么 | 用户语言 | 床垫深处的螨虫皮屑，一吸见分晓 |

**核心原则：用户只为 B 买单。** 三维打分筛出的卖点往往是 F/A 形态，必须改写为 B 形态才能上 KV 和主标题。

### 3.2 改写句式模板

#### 模板 1：标准 FAB 全链（详情页用，完整展开）

```
因为【F 属性】（150AW 大吸力），
所以【A 优势】（比普通无线吸尘器强 50%），
对您而言【B 利益】（床垫沙发深处的螨虫皮屑，吸一遍就现形）。
```

#### 模板 2：F→B 直译（主标题用，F 直接嫁接场景利益）

```
【F 数字/技术】+ 【B 场景结果】
→ "150AW 吸力，床单一遍吸出看不见的脏"
```

#### 模板 3：痛点反推式（B 提前，痛点开场）

```
还在为【痛点】烦恼？【F】让它成为过去
→ "螨虫脸反复长痘？150AW 深度吸除床垫过敏原"
```

#### 模板 4：对比锚定式（用参照物放大 A）

```
【F】= 【熟悉参照物】×【倍数】，【B】
→ "吸力堪比 3 台有线的它，搬家租房清洁一机搞定"
```

#### 模板 5：场景限定式（绑定使用时刻）

```
【使用场景】+【F】+【B】
→ "周六上午的大扫除，60 分钟续航一气呵成，中途不充电"
```

#### 模板 6：数字实证式（可感知度 5 分专用）

```
【F】+【可视化证据】
→ "吸前 vs 吸后：尘盒里的灰絮，就是你的床垫半年没洗的证据"
```

### 3.3 改写三条军规

1. **F 最多保留一个数字**：`150AW + 60 分钟 + HEPA13 + 1.5kg` → 一句话塞 4 个 F，等于 0 个卖点。主标题只留打分最高的那个。
2. **A 必须有参照物**：没有对比的"领先"是空话。参照物选用户熟悉的（普通款/有线款/手洗/大牌同款）。
3. **B 必须含场景或结果**："很好用""更安心"不合格；"床单一遍吸出脏东西""宝宝爬行不怕地板灰"合格。

## 四、正反例对照

### 例 1：食品——无糖气泡水

| | 文案 | 问题/亮点 |
|---|------|----------|
| ❌ 反例 | 精选优质原料，口感清爽，健康好喝 | 三维全 1 分：无数字、无差异、无法感知。"健康好喝"人人能说 |
| ❌ 反例 | 采用赤藓糖醇+三氯蔗糖复配代糖方案 | F 裸奔：工程师语言，用户不知道关我什么事 |
| ✅ 正例 | 0 糖 0 脂 0 卡，冰镇后快乐水的爽感一分不少 | F→B 直译：三个 0 是 F，"爽感不打折"是 B，直击戒糖人群需求强度 5 的痛点 |

### 例 2：美妆——烟酰胺精华

| | 文案 | 问题/亮点 |
|---|------|----------|
| ❌ 反例 | 高浓度烟酰胺，焕亮肌肤，彰显光彩 | "焕亮""光彩"无实证，可感知度 1 分，一票否决 |
| ❌ 反例 | 全网最有效的美白精华 | 广告法极限词，直接违规 |
| ✅ 正例 | 5% 烟酰胺 + 28 天实测，色斑面积肉眼可见变淡 | 数字实证式：浓度是 F，28 天实测补可感知度，"肉眼可见"给 B |
| ✅ 正例 | 熬夜脸的救星：早上涂，暗沉下午才来敲门 | 场景限定式：绑定熬夜场景，B 具体到"暗沉延迟" |

### 例 3：家居——四件套床品

| | 文案 | 问题/亮点 |
|---|------|----------|
| ❌ 反例 | 严选新疆长绒棉，匠心工艺，舒适亲肤 | "匠心/舒适"双无感知；长绒棉是 F 裸奔，没说关用户什么事 |
| ✅ 正例 | 新疆长绒棉，睡过才知道云朵不是比喻 | F→B 直译：材质做信任背书，利益落在体感比喻 |
| ✅ 正例 | A 类母婴标准，宝宝同床睡也放心的四件套 | 差异度不高但需求强度 5（有孩家庭安全焦虑），凭单维度封顶进入主打 |

### 例 4：3C——降噪耳机

| | 文案 | 问题/亮点 |
|---|------|----------|
| ❌ 反例 | 智能主动降噪，聆听纯粹之声 | 无数字无对比，"纯粹之声"无法验证 |
| ❌ 反例 | 降噪深度 42dB，宽频降噪，专业声学调音 | 三个 F 堆砌，军规 1 违规，用户无感 |
| ✅ 正例 | 42dB 深度降噪，地铁进站那一声轰鸣，归零 | 数字 F + 场景 B：把 dB 翻译成"地铁轰鸣消失"的具象瞬间 |
| ✅ 正例 | 通话像换了个房间：地铁里开会，对方只听见你的声音 | 场景限定式：绑定通勤开会高频痛点，B 可感知 |

### 例 5：宠物——猫粮

| | 文案 | 问题/亮点 |
|---|------|----------|
| ❌ 反例 | 营养均衡，适口性佳，猫咪爱吃 | "适口性佳"是厂商语言，且人人可说，差异度 1 分否决 |
| ✅ 正例 | 92% 动物性原料，挑食三年的猫第一次光盘 | F→B 直译 + 评论区实证："光盘"比"爱吃"可感知一万倍 |
| ✅ 正例 | 主子吃一个月，毛顺到反光 | 长期利益具象化：把"美毛"改写为"反光"的可视化结果 |

### 例 6：动漫周边——吧唧

| | 文案 | 问题/亮点 |
|---|------|----------|
| ❌ 反例 | 精美徽章，二次元必备 | 无 IP 名、无正版信息，圈内人一眼假，可感知度 1 分 |
| ❌ 反例 | 全网最低价吧唧 | 违禁词 + 谷子圈忌讳低价暗示（易被联想盗印），双重否决 |
| ✅ 正例 | 官方正版授权《死神》，58mm 马口铁工艺，品相无瑕直出 | 正版授权是谷子圈需求强度 5 的第一卖点；58mm/马口铁是 F；"品相无瑕"是 B |
| ✅ 正例 | 自推新柄首贩，附授权标可验真，痛包C位预定 | 圈层语言（自推/柄/痛包）精准命中 TA；"可验真"消除盗版顾虑 |

## 五、打分 → 改写 → 投放 的完整链路示例

**商品**：电吹风机（个护电器，对照《类目场景库》4.3）

| 步骤 | 产出 |
|------|------|
| 卖点池 | 高转速电机 / 负离子养护 / 3 分钟快干 / 低辐射 / 11 档风温 / 500g 轻机身 |
| 三维打分 | 3 分钟快干（4+4+5=13 主打）；负离子（3+3+2=8 淘汰）；500g 轻机身（4+3+5=12 次级） |
| FAB 改写 | 主打：`11 万转电机，长发 3 分钟吹干，赶早八不迟到`；次级：`500g 比手机还轻，举着吹头不酸臂` |
| 进文案库 | 主打卖点套文案库 T1（数字型主标题）+ C3（结果预演 CTA） |
| 进 KV 场景 | 对照《类目场景库》4.3「3 分钟干发不伤发」场景：清晨梳妆台，发丝飞扬动态 |

## 附：卖点自检清单

- [ ] 打过三维分：主打卖点总分 ≥ 12，无一维 = 1
- [ ] 打分时带着 TA 画像（对照《类目场景库》对应子类目）
- [ ] 主标题里 F 数字 ≤ 1 个，且已被翻译成 B
- [ ] A 有参照物，B 有场景或结果，无"高端/匠心/优质"类空词
- [ ] 功效类卖点有实证依据（实测数据/检测报告/评论佐证）
- [ ] 无广告法极限词（最/第一/国家级/顶级），无医疗功效表述
- [ ] 同一卖点在主标题、KV 画面、详情页三处口径一致
