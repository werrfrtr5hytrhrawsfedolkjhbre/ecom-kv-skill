> **使用方式**：提案阶段随方案附上画布规格；生图阶段把尺寸/比例写入提示词；交付阶段逐项核对。
> **更新**：平台规则可能调整，本表为内置数据，改动只改本文件。

## 二、平台逐项说明

### 2.1 淘宝 / 天猫

- 尺寸：主图 800×800 以上，1:1 比例
- 文件：单张 ≤ 3M
- 限制：主图无大面积文字（文案放 3:4 竖版图或详情页）

### 2.2 京东

- 尺寸：主图 800×800 以上，1:1 比例
- 文件：单张 ≤ 3M
- 限制：主图必须为纯白色底（全平台最严，见《设计硬规则》P6/P9 冲突处理）

### 2.3 拼多多

- 尺寸：主图 750×750 以上，1:1 比例
- 文件：单张 ≤ 3M
- 限制：主图无极限词（对照《广告法违禁词清单》）

### 2.4 抖音商城

- 尺寸：主图 800×800 以上，1:1 比例
- 文件：单张 ≤ 5M
- 限制：商品主体占图片 70% 以上；主图无二维码等联系方式；信息流场景执行《设计硬规则》P5 严标准（文字面积 ≤ 20%）

### 2.5 小红书

- 尺寸：3:4 比例
- 用途：电商笔记封面，信息流场景，同样执行文字面积 ≤ 20% 严标准

## 三、跨平台通用执行规则

1. **安全区**：主卖点、价格、CTA 等关键信息避开画面四角与边缘 10% 区域（平台角标、按钮、水印常驻位置）。
2. **画幅适配**：同一设计语言适配 1:1 与 3:4 时重新构图，禁止拉伸裁剪（见《设计硬规则》P9）。
3. **文字规范**：无论平台是否强制，主图文字均遵循《设计硬规则》P5（文字面积 ≤ 30%）。
4. **极限词**：所有平台均按《广告法违禁词清单》执行；拼多多平台标注「主图无极限词」为强制项，其余平台同样从严。

## 附：交付核对流程

- [ ] 尺寸像素与比例符合目标平台要求
- [ ] 文件大小在平台限额内（3M / 5M）
- [ ] 关键信息（主卖点/价格/CTA）在安全区内
- [ ] 平台特殊限制逐项通过：白底 / 无大面积文字 / 主体占比 70% / 无二维码 / 无极限词
